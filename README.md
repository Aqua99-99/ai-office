# AI 사무실 — 트레이딩 사무실

AI 직원 12명이 증권사 팀처럼 역할을 나눠 종목 하나를 분석하고, **한국어 보고서 웹페이지**와 **5단계 최종 등급**(매수·비중 확대·보유·비중 축소·매도)을 내요.
[TradingAgents](https://github.com/TauricResearch/TradingAgents)의 회사 구조를 그대로 옮겼고, 생각하는 일은 모두 **Claude 구독**으로 해요. API 키 비용이 따로 들지 않아요.

> 연구용 분석이에요. 투자 권유가 아니며, 같은 날짜로 다시 돌려도 결과가 달라질 수 있어요.

## 직원 12명

| 단계 | 직원 | 하는 일 |
|---|---|---|
| 1. 조사 (동시에) | 차트 분석가 · 투자심리 분석가 · 뉴스·거시 분석가 · 재무 분석가 | 주가·지표, 뉴스·커뮤니티 분위기, 금리·환율, 재무제표 |
| 2. 토론 | 강세 연구원 ↔ 약세 연구원 | 사야 할 이유 vs 피해야 할 이유 |
| 3. 계획 | 리서치 매니저 | 토론 심판, 투자 계획과 등급 |
| 4. 거래 | 트레이더 | 매수/보유/매도, 진입가·손절가·비중 |
| 5. 위험 점검 | 공격형 · 보수형 · 중립형 리스크 담당 | 제안을 세 관점에서 토론 |
| 6. 결정 | 포트폴리오 매니저 | 지난 교훈까지 반영해 최종 등급 |

판단은 `기억/`에 남고, 5거래일 뒤 실제 주가(시장지수 대비)로 채점돼서 다음 분석 때 **교훈**으로 쓰여요.

## 쓰는 방법 1 — 내 컴퓨터 (Claude 데스크톱 앱 / Claude Code)

플러그인으로 설치해요.

```
/plugin marketplace add Aqua99-99/ai-office
/plugin install trading-office@ai-office
```

그다음 채팅으로 말하면 돼요.

- "삼성전자 분석해줘", "NVDA랑 SK하이닉스 분석해줘"
- "2026-09-01 기준으로 005930.KS 분석해줘" (그날 알 수 있던 정보만 써요)
- "삼성전자 100주 갖고 있는데 어때?"
- "트레이딩 사무실 성적표 보여줘"

처음 한 번은 데이터 도구 설치에 1~3분 걸려요(Python 3.11 이상 또는 `uv` 필요, 없으면 알아서 안내해요).

## 쓰는 방법 2 — GitHub에서 자동 (컴퓨터가 꺼져 있어도)

1. 내 컴퓨터 터미널에서 `claude setup-token` → 나온 토큰을 복사
2. 이 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   이름 `CLAUDE_CODE_OAUTH_TOKEN`, 값에 토큰 붙여넣기
3. 저장소를 **Private**으로 바꾸기 (공개로 두려면 Variables에 `AIO_ALLOW_PUBLIC` = `1`)
4. `관심종목.txt`에 종목 적기

이러면

- **평일 아침 7시 40분**에 관심종목을 분석하고 결과를 이슈(라벨 `AI 보고`)로 알려 줘요
- **Issues → New issue → 분석 요청**을 쓰면 그 종목을 분석해서 그 이슈에 답장해요
- **Actions → 트레이딩 사무실 → Run workflow**로 바로 시킬 수도 있어요

보고서 웹페이지는 실행 기록의 Artifacts에서 받거나 저장소의 `보고서/` 폴더에 있어요.

선택: `FRED_API_KEY`(무료, 미국 거시지표)를 Secrets에, `SEC_EDGAR_USER_AGENT`(예: `이름 메일주소`)를 Variables에 넣으면 데이터가 늘어나요.

## 사용량 감각

종목 하나를 분석할 때 직원 12명이 한 번씩(토론 1라운드 기준) 일해요. 구독 사용량 한도 안에서 하루 몇 종목 정도가 알맞아요. 토론 라운드를 늘리거나 종목이 많으면 그만큼 늘어나요.

## 알아둘 점

- 한국 종목은 해외 커뮤니티(StockTwits·Reddit) 자료가 거의 없어서, 분석가들이 국내 뉴스를 웹 검색으로 보충해요.
- 과거 날짜로 분석하면 그날 이후 정보는 쓰지 않아요. 다만 일부 자료(과거 시점의 기업 개요 등)는 "자료 없음"이 될 수 있어요.
- 채점 기간 5거래일은 짧아요. 장기 투자 논리는 성적표만으로 판단하지 마세요.
